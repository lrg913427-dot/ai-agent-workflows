# AI Agent Workflows

基于 AI Agent 的智能工作流自动化系统，支持飞书、企业微信等多平台集成，用于企业电销培训、语音对话系统等场景。

## 项目概述

本项目构建了一套完整的 AI Agent 工作流系统，核心能力包括：

- **多平台集成**：飞书、企业微信、TikTok 等主流平台
- **语音对话系统**：基于腾讯云 TTS/ASR 的智能语音交互
- **电销培训系统**：企业电销话术库、智能陪练、数据分析
- **自动化工作流**：日程管理、会议纪要、任务追踪

## 技术栈

- **AI 模型**：Hermes、Claude、GPT-4
- **语音技术**：腾讯云 TTS、ASR
- **平台集成**：飞书 Lark CLI、企业微信 API
- **视频生成**：Remotion + Hunyuan Image
- **开发工具**：WorkBuddy、Claw、Node.js/TypeScript

## 应用场景

| 场景 | 描述 |
|------|------|
| 企业电销培训 | 话术库管理、新人培训、智能陪练 |
| 语音对话系统 | 腾讯云 TTS/ASR 集成、智能客服 |
| 内容创作 | TikTok 视频脚本、公众号文章、3D 黏土动画 |
| 数据分析 | 不锈钢出口数据、TikTok 电商数据追踪 |

## 项目成果

- 企业电销培训：新人时长缩短 30%，首周通过率提升 50%
- 语音系统：支持实时语音对话，响应时间 < 2s
- 内容产出：公众号「下班后的 OPC」持续运营
- 视频制作：30 集 3D 黏土英伦乡村系列视频
